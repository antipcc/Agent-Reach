## 1. 故障诊断总则与安全规范

### 1.1 故障的四大来源

行业资料普遍把印刷故障的原因归为四类，诊断时应逐类排查，不要一上来就拆机器：

| 类别 | 典型内容 |
|---|---|
| **机械因素** | 轴承磨损、齿轮损坏、叼牙失灵、滚筒中心距/包衬不当、传动件松动 |
| **工艺因素** | 水墨平衡失控、辊压调整不当、印刷压力设定错误、机速与墨性不匹配 |
| **材料因素** | 纸张（含水量、纸粉、卷曲、静电）、油墨（粘度、干燥性、乳化）、润版液（pH、导电率）、橡皮布老化 |
| **环境因素** | 车间温湿度波动、电网电压不稳、粉尘 |

### 1.2 推荐诊断流程

1. **问**：先问操作人员——故障何时开始？之前动过什么（换纸、换墨、换版、洗车、调压力、停机重启）？绝大多数"突发"故障都跟随某个最近的变更。
2. **看**：读控制台（CP-tronic/CP2000/Press Center）的报警信息和服务菜单诊断项；看印张本身——故障在叼口还是拖梢、固定位置还是游动、单色组还是全部色组，这些都直接指向故障源。
3. **听、闻、摸**：异响（齿轮/轴承）、焦糊味（电机/电路板）、发热部位（胶辊、轴承座）。
4. **分区隔离**：按"输纸 → 定位 → 交接 → 印刷（水路/墨路/滚筒）→ 收纸"的走纸链路逐段隔离；多色机可逐色组断开（脱开合压、抬起水墨辊）判断故障在哪个机组。
5. **先易后难、先外后内、先工艺后机械**：先查纸张/油墨/润版液和调整参数，再查外围传感器与气路，最后才动机械与电气核心件。
6. **换件对比**：可疑的电路板、传感器、吸嘴橡皮，用同型号好件替换验证（海德堡各机组同类板卡常可互换槽位对比，注意先记录原始参数/跳线）。
7. **一次只改一个变量**，每次改动后试印验证，避免叠加调整把机器越调越乱。

### 1.3 维修安全规范

- 检修前**断电挂牌**（Lockout/Tagout），泄放气路与液压残压。
- 在滚筒区、辊隙区作业时只允许用**点动（寸动）或盘车**方式转动机器，双人作业时必须有明确的呼应确认制度。
- 护罩、光电安全检测、急停回路出现故障时**只能修复，不能短接屏蔽**。CP2000 上可以临时屏蔽某些检测（如边规报警）用于诊断，生产前必须恢复。
- 清洗剂、异丙醇（IPA）远离热源；洗车布单独存放防自燃。

## 3. 开机与电气控制系统故障

### 3.1 机器无法启动

按以下顺序排查（来自多家维修商与用户手册的共同经验）：

1. **报警信息**：控制台是否有未清除的报警（安全护罩、急停按钮被按下未旋出、收纸/输纸区"纸张未清空"类报警等）。CD102-5 曾有 CP2000 报"收纸处纸张未清空"而实际已清空的案例——多为该区域检测电眼脏污或位置漂移，清洁/复位传感器即可。
2. **安全回路**：逐个检查急停按钮、护罩行程开关、光电人体检测。
3. **气源**：中央气源/机载气泵压力是否达到设定值，气压不足会禁止启动。
4. **电源**：主开关、三相进线是否缺相松动、保险（熔断器）是否完好、电源线路是否过载；电网电压波动大的厂区建议为印刷机配置专用稳压器（如 SBW 系列印刷机专用稳压器）。
5. **控制面板**：显示屏无显示、按键无响应时，先查控制台供电与通讯，再考虑工控机/显示器硬件（见 §3.3）。

### 3.2 主传动与驱动系统故障

- **运行中"闷车"（突然抱死停机）**：先排除机械性卡阻（卡纸进滚筒、异物、轴承烧结），再查电气。典型案例：CD-102（CP2000）运行中显示"人体进入安全检测对主传动装置锁定""吹气管位置错误"，起初不影响运行，约十分钟后闷车并报开关柜和可信度（Plausibility）检测故障——最终确认是**吹气管位置检测开关移位**造成的误触发，调整开关位置后恢复正常。启示：**安全检测类报警即使"暂不影响运行"也必须立即处理**，否则会升级为锁机。
- **主电机不转/转速异常**：检查主驱动控制板（老机型如 QM46 的 15-01 错误即指向 MRK 主电机控制板）、功率变换单元（CD74 等机型的 SLT 功率输出单元、SVT 连接单元）、测速/位置编码器及其连接线。
- **变频器/驱动器过流报警**：输出电流超过约 1.5 倍额定即触发保护。依次检查：三相进线与输出端子是否松动、是否有短路放电痕迹、电机绝缘、驱动板输出电压是否平衡；反复过流通常是功率模块或电机问题，不要盲目复位强开。
- **CP2000"圆圈 T"标志**：表示动态测试（Dynamic Test）中检测到电子板故障，需进服务诊断菜单读出具体板卡位置。

### 3.3 控制台与电路板故障

海德堡电气故障中，可修复率较高的板卡类故障（国内多家工控维修商的常见维修项）包括：

- **CP2000 工控机/主板**：死机、无法进系统、通讯中断。
- **触摸屏/显示器**（如 CP.150.0338）：黑屏、亮度暗、花屏出线条、触摸失灵。
- **LTK500 水辊（水斗电机）控制板**——海德堡机上出名的易损板之一。
- **KLM4 等驱动板、IDEB3-16 墨驱（墨键电机）控制板、电眼放大器板、风柜（AirStar）电机驱动板、各类开关电源板**。
- 维修此类板卡多为电源部分损坏（开关管、电源芯片、启动电路及周边分立元件烧毁），有经验的维修商可元件级修复；无维修能力时整板更换。
- **CP-tronic 老机型注意**：主机板依赖后备电池保存参数，电池低电报警要及时换电池，否则断电后机器参数/预置数据丢失。

> 电路板送修/更换前，务必**拍照记录接线、槽位、跳线和地址开关设定**；同型号板卡在不同槽位功能不同（见 §14 的 HAK/EAK 槽位编号说明）。

## 4. 输纸系统（飞达）故障

飞达（Feeder，给纸机）故障占日常停机的比例最高，绝大多数是**调整与清洁问题**而非零件损坏。

### 4.1 基准调整参数（经验值）

| 项目 | 经验基准 | 说明 |
|---|---|---|
| 分纸吸嘴距纸堆面 | 3～5 mm | 通过压纸脚位置/纸堆自动升降跟踪量调整 |
| 飞达头与纸堆间距 | 约 8～10 mm | 过大易空张/双张，过小易卡纸 |
| 分纸吸嘴姿态 | 垂直对准纸堆后边缘 | 吸气时机 = 纸张刚被吹松分离的瞬间 |
| 送纸（递纸）吸嘴 | 与接纸辊（轮）速度同步 | 不同步会拉歪、拉皱纸张 |
| 松纸吹嘴 | 吹散最上面 3～5 张纸呈"浮起"状 | 吹风过强顶起多张 → 双张 |
| 压纸脚 | 压住第二张纸并控制纸堆高度 | 弹簧疲劳、位置过高都会失效 |

### 4.2 空张（吸不起纸/输纸中断）

**原因排查顺序**：

1. 吸嘴橡皮圈老化、开裂、孔径变形 → 更换（易损件，应常备）。
2. 气路漏气：分气阀（旋转配气阀）磨损、气管破裂、接头松脱。
3. 气泵真空度不足（见 §10）。
4. 吸嘴距纸堆过远：调整压纸脚高度或纸堆自动跟踪高度。
5. 纸张问题：纸太重超出吸力、纸堆四角翘曲（荷叶边）使吸嘴吸不实。
6. 输纸检测电眼脏污误报空张 → 每周清洁（见 §15）。

### 4.3 双张、多张

1. 松纸吹风过大或压纸脚失效，一次吹起/带起多张。
2. 纸张粘连：裁切刀口粘边、静电吸附（见 §4.5）、纸张受潮。上纸前**必须扇纸（松纸）撞齐**。
3. 分纸吸嘴吸力过大或距纸堆过近。
4. 双张检测器（机械式间隙或超声波式）间隙设定与纸厚不符、检测器失灵 → 按当前纸厚重新标定；机械式检测辊间隙用塞尺校验。

### 4.4 歪张、迟到纸

- **歪张的机械性根因**：飞达整体与主机不平行（安装或撞击后移位）。校正飞达相对主机的平行度，并调节飞达两侧与走纸杆，使**两侧送纸快慢一致**。
- 两侧分纸吸嘴高低/吸风不一致、两侧松纸吹风不对称，也会造成规律性歪张。
- 输纸带（线带）张力不均、压纸轮压力两侧不一致 → 纸张在输纸台上跑偏。
- 迟到纸：吸嘴吸力偏小、接纸时机偏晚、输纸带打滑；到达前规过晚会被电眼判废停机。

### 4.5 纸张静电与变形

静电的表现：分纸困难、纸张无法撞齐、输纸不畅定位不准、收纸不齐。**五类对策**（可组合使用）：

1. **调湿存放**：纸张进厂后在印刷车间环境放置足够时间；车间控制在温度 18～25 ℃、相对湿度 60%～70%。
2. 车间加湿（地面洒水、加湿器）。
3. 适当**降低机速**，减少摩擦起电。
4. 使用抗静电剂。
5. 在输纸板附近安装**离子风棒/静电消除器**。

纸张卷曲、荷叶边（边缘波浪）：干燥环境纸张失水发脆、潮湿环境吸水起波浪，都会造成输纸褶皱卡纸。落差大的季节，纸库与车间之间要有温湿度过渡，必要时先吊晾/压平处理。

### 4.6 一个容易被忽视的根因

有维修商总结：设备搬迁或运输后"试机完好、回厂频繁卡纸"，多因**飞达走纸组件在运输震动中整体偏移**——吸嘴高度、前后间距、吸风平衡全部漂移，需要按手册基准全面复校，而不是逐个救火式微调。

## 5. 定位与交接（前规/侧规/递纸牙）故障

### 5.1 前规、侧规（拉规）

- **前规**：定位纸张前边缘。前规挡纸舌高度应按纸厚设定（约为纸厚的 2～3 倍的通过间隙，以随机手册为准）。前规压纸辊在印张上留下痕迹时，用海德堡认可的清洁剂清洁；清洁后仍转动发涩的应更换。
- **侧规**：拉纸量不足/过量都会定位不准。检查侧规拉纸轮压力与磨损、侧规定位面是否有纸粉堆积。**侧规偏心套位置装错**会导致永远拉不到位，需拆下重新调整。**拉规盖板与台面间隙过大**，薄纸会窜动定位不准。
- CP2000 可在诊断中**屏蔽边规（侧规）到位报警**——诊断完必须恢复，长期屏蔽会放走大量废张。

### 5.2 递纸牙、摆动牙与滚筒叼牙

- **"死牙"**（个别叼牙失去弹性或卡死不动作）：叼纸力不足，造成套印不准、局部重影、叼口"剥皮"（纸面被撕起）。逐个检查牙片开闭灵活性与叼力（可用薄纸条逐牙拉力测试，各牙手感应一致），更换失效的牙片、牙垫和弹簧。
- **牙垫、牙片磨损**：叼口打滑 → 套准漂移。磨损件成对更换后需重新校牙。
- **摆动牙（递纸摆）开牙时机/开牙量不对**：开牙过小，纸张交接瞬间被弹回或撕坏。点动机器至递纸牙运行到输纸台板交接位置检查开牙量与交接时机。
- **递纸滚筒交接失准造成皱纸、烂纸**：典型机械根因是**开牙滚子（凸轮随动轴承）磨损烂损**——更换新件；应急时可按标准尺寸加工或选用国标轴承配作销轴代用。
- 交接关系（递纸牙→压印滚筒→传纸滚筒逐级交接量）失准的，按手册规定的交接量重新校验，勿凭手感乱调。

## 6. 套印不准的系统性排查

套印不准是复合故障，务必**先分类再动手**——看废张上的规矩线：

| 特征 | 指向 |
|---|---|
| 单色组整体偏移、方向稳定 | 该色组装版/版夹微调问题，直接在控制台校版 |
| 所有色组都相对纸边漂移、张与张随机 | 定位系统（前规/侧规/递纸）或纸张问题 |
| 轴向（左右）忽大忽小 | 侧规拉纸不稳、纸张歪张 |
| 周向（上下）渐变漂移 | 纸张含水变形（紧边/荷叶边）、橡皮布松、包衬错误 |
| 叼口准、拖梢不准（扇形张开） | 纸张变形（fan-out），机械上很难根治，用工艺补偿 |
| 局部区域套不准 + 重影 | "死牙"、叼力不均（见 §5.2） |

**纸张含水量因素的工艺对策**（多篇资料一致推荐）：

- 印前让纸适应车间温湿度；含水不均的纸可**先空压过水一遍**（跑一遍水不上墨）或吊晾，使含水量均匀。
- 正式印刷前先走几张检测纸张变形量，再决定前规/版位补偿。
- 双面/多次过机活件，两次印刷之间存放条件保持一致。

**机械性根因**（工艺补偿无效时才考虑）：版滚筒/橡皮滚筒轴承磨损（窜动量增大）、纵向微调机构松动、传动齿轮侧隙过大、老旧设备的"甩角"（印品某一角规律性甩动，多为交接与滚筒系统综合磨损，需大修解决）。

## 7. 印刷质量故障

### 7.1 墨杠（与滚筒轴向平行的深色条杠）

按杠的规律判断来源：

1. **等距分布的粗杠，间距 = 齿轮齿距**：滚筒齿轮精度差或磨损 → 检查齿侧隙，必要时适当减小滚筒中心距或更换齿轮。
2. **叼口附近固定位置条杠**：滚筒轴承磨损，合压瞬间冲击 → 更换轴承。
3. **随机性振杠**：齿轮间嵌入墨皮、纸毛等污物引起振动 → 清洗齿轮、检查润滑。
4. **墨辊性杠**：靠版墨辊压力过大或辊枕（肩铁）脏污 → 重调辊压（见 §8.1）、每天清洁滚枕。

### 7.2 水杠（白亮条杠）

- 多为**靠版水辊与印版压力过重**（叼口处出现固定亮杠），摩擦磨版并挤走墨层；压力过轻则版面供水不足起脏。
- 调整次序：**先调水辊与串水辊（计量辊）间压力，再调水辊与版面压力**；上下水辊都要调时先下后上，上辊压力略小于下辊。
- 水辊绒套/胶辊表面不均、辊芯弯曲也会出周期性水杠，检查辊体跳动。

### 7.3 重影（Ghosting/Doubling，网点出现双重轮廓）

1. **橡皮布松动**：最常见。按规定扭矩重新绷紧橡皮布（新橡皮布印刷数百张后要复紧）。
2. **包衬不当**：按机型规定的衬垫数据包衬，过厚会加大挤压滑移。
3. **机组间交接不准、纵向微调机构松动、滚筒轴承磨损**：检查调节纸张定位交接部件。
4. **纸张抖动/静电**、纸尾拍打橡皮布（薄纸高速时）：调整导纸风、适当降速。
5. 局部重影伴套印不准：回查"死牙"（§5.2）。

### 7.4 糊版、起脏（非图文部分上墨）

- **油墨太稀/严重乳化**：墨斗内加原墨或更换油墨；检查润版液用量是否过大造成乳化。
- **靠版水辊/计量辊压力失当**：拆下计量辊用 0.1 mm 钢片（塞片）重新校平两端压力；靠版辊压杠宽度调至 3～4 mm。
- **墨辊与印版压力过大**：磨版生热，网点扩大糊死 → 重调辊压。
- **润版液失效**：表面张力过大润湿不足 → 检查 pH/导电率/IPA 浓度（§9.1）。
- **油墨抗水性差**：乳化后油墨颗粒吸附到版面空白区 → 换抗水性好的油墨。

### 7.5 花版、掉版、耐印力低（图文部分掉墨、印版早衰）

- **主因是机械摩擦**：版滚筒与橡皮滚筒压力过大 → 版面砂目磨平，先糊版后花版。按理想压力和正确包衬数据控制滚压。
- **滚筒轴套磨损**使窜动量加大，水辊、墨辊、橡皮滚筒对版冲击力增大 → 耐印力骤降，需检修滚筒轴承。
- **润版液 pH 过低（过酸）或过高**都会腐蚀/磨损版基。PS 版润版液以 pH 5.0～6.5 为宜（不同药水配方按供应商标准）。
- **纸粉、砂粒多的纸张**磨版；**油墨粘度过高或墨量过少**也加剧磨版。

### 7.6 背面蹭脏、粘脏（Set-off）

- 原因：墨层过厚、油墨渗透干燥性差固化慢、纸张吸收性差、喷粉量不足、收纸堆过高。
- 对策：通过加大水墨平衡窗口降低墨层（配合加深墨色的油墨）、加干燥剂/换快固油墨、增大喷粉量并选对喷粉粒径、**降低收纸堆高度勤下纸**、用隔纸板分垛。
- 喷粉量过大反而造成"粉化"（表面粗糙、影响覆膜上光），要找平衡点；喷粉装置堵塞的处理见 §11.2。
- 输纸线带、压纸轮脏污把未干墨迹蹭到下一张的正面——周保养清洗输纸线带、调整压纸轮压力。

### 7.7 墨皮、脏点（Hickeys）

墨斗/墨辊上的干墨皮、纸毛纸粉、车间粉尘落到版面或橡皮布 → 图文中出现实心小点带白圈。对策：勤洗橡皮布（易掉毛掉粉纸张更要勤洗）、清理墨斗墨皮、更换过度老化的墨辊（表面裂纹藏污）、控制车间粉尘。

### 7.8 橡皮布相关故障

- **失去弹性/压缩层疲劳**：墨色虚淡、网点不清、文字变形 → 更换橡皮布或适当加大包衬。
- **局部低凹（smash，被卡纸/异物压伤）**：轻微的可用橡皮布修复剂应急，明显低凹更换；换下的可翻转用于要求低的活件。
- **张紧度**：过紧则胶层变薄弹性差、易塑性变形；按扭矩扳手规定值绷紧。
- **长期印同一幅面**造成边界处塑性变形（印大幅面时出现"印痕框"）→ 定期轮换橡皮布、及时清洗堆积的纸毛纸粉（堆积物会局部增压加速塑变）。
- 交班、换活必洗橡皮布和压印滚筒。

## 8. 输墨系统故障与调校

### 8.1 墨辊压力（压杠宽度）标准与调法

- **靠版墨辊**：先调其与**串墨辊**的压力，再调其与**印版**的压力，且对串墨辊的压杠应略大于对版压杠（约宽 1 mm）。对版压杠宽度以 **3～4 mm**（部分资料 3～5 mm）为宜。
- **检查方法**：停机点动到合适位置，手动落下靠版墨辊再抬起，观察 4 根靠版墨辊在版面留下的墨杠宽度是否达标且两端一致。
- **传墨辊**：与墨斗辊、串墨辊间的压力——按传墨按钮点动使传墨辊摆到最近位置，两侧用 0.1 mm 塞片试抽，力感一致为准；与串墨辊压杠约 3 mm。
- 两端压杠不一致 = 辊子锥度磨损或调偏，先排除辊体磨损再调偏心。

### 8.2 墨辊老化、晶化（釉化）

- **晶化成因**：油墨/润版液残留物（钙盐、纸粉、药水添加剂）在压力与热量作用下在辊面结晶积釉 → 辊面光滑发亮、亲墨性下降、传墨不良、水墨平衡难控。
- **处理**：用专用的除钙除釉清洗膏深度清洗（普通洗车水洗不掉钙化层）；轻度晶化可用浮石粉配合清洗剂手工打磨；表面出现细小裂纹的墨辊及时研磨或更换。
- **预防**：避免用劣质煤油/汽油/酒精洗辊（加速老化釉化）；洗车程序走完全程让刮墨板刮净；控制辊间压力（压力过大挤压发热会使胶辊膨胀脱壳报废）；避免日光直射（光老化）。
- 传墨辊两端保持清洁，防止滴墨结块阻碍其摆动。

### 8.3 墨控（墨键/墨斗）故障

- 个别墨键不跟随预置值：多为该区墨键电机或其驱动板（如 IDEB 系列墨驱板）故障、电位器反馈失灵 → 进 CP2000 服务诊断逐键测试，维修/更换对应执行器或板卡。
- 整列墨键失控：查该印刷单元墨控板供电与通讯（CAN 总线接插件）。
- CP2000 预置数据不合理时，检查 CIP3/CIP4 油墨预置曲线是否与当前纸墨匹配，重新学习校正曲线。

## 9. 润版系统（Alcolor）故障

### 9.1 润版液关键参数（日常必控）

| 参数 | 推荐范围（经验值） | 失控后果 |
|---|---|---|
| pH 值 | **4.8～5.5**（版材寿命角度可放宽到 5.0～6.5） | 过酸→掉版/腐蚀版基、油墨干燥受阻；过碱→起脏 |
| 导电率 | **800～1500 μS/cm**（以原水导电率为基线记录增量） | 过高说明药水浓或污染，过低说明药水不足 |
| 温度 | **8～15 ℃**（常用 10～12 ℃） | 过高→酒精挥发快、乳化加剧 |
| IPA（异丙醇）浓度 | 常用 8%～12%（按机型与药水说明） | 加酒精会使导电率下降、pH 略升——用折光仪/酒精比重计单独计量 |

**管理要点**：定量配比法配液（固定水量、药水量、IPA 量），搅拌均匀静置约 20 分钟再加入循环箱；**每周**用仪器实测 pH 与导电率并清洗润版箱过滤海绵；**每半月**清理一次润版液循环箱（油墨、纸粉污染会让导电率读数失真）。

### 9.2 润版液水箱（循环制冷机组）故障

**故障现象：不制冷/温度偏高、酒精挥发过快。** 按下列顺序诊断：

1. 显示屏温度设定值是否被误改。
2. **压缩机散热器（冷凝器）表面积尘堆积** → 清理（最常见原因）。
3. **冷却过滤器/管路堵塞** → 拆洗。
4. 制冷压缩机**过电流保护开关**是否跳开、**高低压保护开关**状态。
5. 循环水泵是否运转、流量是否正常（泵不转则版面供不上水，机器会报水量报警）。
6. 以上正常仍不制冷 → 制冷剂泄漏或压缩机本体故障，找制冷专业维修。

### 9.3 水辊与供水故障

- 水辊压力调整次序见 §7.2；计量辊两端压力用 0.1 mm 钢片校平。
- 水斗辊/计量辊表面亲水层污染（墨污、钙化）→ 供水不均、局部起脏，用专用清洗剂恢复。
- 水辊电机不转、转速不跟机速：LTK500 类水辊驱动板故障是海德堡的高发点（§3.3）；也检查测速反馈与接插件。
- 绒套水辊（老机型）绒套起毛、松脱 → 更换绒套并充分浸润。

## 10. 气动与真空系统故障

飞达吸力、递纸吸嘴、收纸吸鼓、喷粉、合压离压气缸都依赖气路，气路故障常伪装成"输纸故障"。

1. **气泵（真空泵/鼓风泵）**：
   - 干式旋片泵**碳精片（叶片）磨损**是压力/真空度下降的头号原因，按小时数定期更换；
   - 进气滤芯、消音器堵塞 → 定期清理更换；
   - 泵体过热检查散热与皮带张力。
2. **旋转分气阀（配气盘）**：磨损或密封面拉伤 → 吸/吹时序错乱，输纸时好时坏，研磨或更换。
3. **管路**：老化气管破裂、接头松脱造成漏气——听嘶嘶声、涂皂液查漏；分段夹管定位漏点。
4. **电磁阀**：卡滞、线圈烧毁 → 对应执行动作缺失（如某组合压不动作），用手动应急按钮判断阀体还是电控问题。
5. **压力开关/传感器**漂移 → 机器误报"气压不足"拒绝启动，用外接表校验后调整或更换。
6. 中央供气机型（AirStar 风柜）：风柜内电机驱动板故障也是可维修的常见项（§3.3）。

## 11. 收纸系统故障

### 11.1 收纸不齐

按以下顺序检查（来自维修案例总结）：

1. **收纸减速装置**：减速吸鼓电机不转 → 修复或更换；**传动软轴断裂** → 更换；**减速吸鼓胶圈（O 型密封圈）断裂/老化** → 更换（应急时可用尺寸相符的国产 O 型密封圈替代）。
2. 齐纸器（前齐纸板、侧齐纸器）行程与时机设定不当。
3. 收纸吹风/真空减速风量与纸张不匹配（薄纸减风、厚纸加风）。
4. 纸张静电（§4.5）。
5. 收纸链条与牙排：链条伸长、牙排开牙凸轮磨损 → 放纸位置漂移；周保养清洁加油，磨损超标更换。

### 11.2 喷粉装置故障

喷粉防粘装置不正常时按顺序处理：

1. 检修喷粉气泵（气源压力）。
2. **清理粉筒滤网**（经常性维护项）。
3. 检查密封片垫，损坏及时更换。
4. **逐个疏通喷粉嘴/喷粉管的堵塞**（受潮结块是主因；每月彻底疏通一次，粉仓防潮）。
5. 检查输粉胶管/胶带老化，必要时更换。

### 11.3 收纸区其他

- 收纸叼牙磨损 → 拖梢甩动、收纸卷角。
- 真空减速辊（吸气辊）吸孔堵塞 → 清理。
- 印张未干堆叠过高 → 背面蹭脏（§7.6），勤下纸、用隔板。

## 12. 卡纸与闷车的处理与预防

### 12.1 正确处理步骤

1. 立即停机（通常安全系统已自动停机），**挂检修牌**。
2. 查明卡纸位置与范围后，**只用点动/盘车沿走纸方向**转动机器取纸；**严禁反转硬拉**——反转会顶坏叼牙、双张检测器和递纸机构。
3. 卡入滚筒间的纸要分层撕出，清点碎纸确保无残留（残片会造成下一次故障或印品低凹）。
4. 取净后检查：橡皮布有无压伤低凹（§7.8）、包衬是否移位、叼牙有无变形、双张检测器是否移位，然后空转试车再合压试印。
5. 闷车（过载抱死）后：先盘车确认机械无卡阻，再复位驱动报警；反复闷车必须找根因（§3.2），不可反复强行复位。

### 12.2 预防

- 双张检测器按纸厚标定，宁灵敏勿迟钝。
- 飞达按 §4.1 基准定期复校（尤其搬迁、撞击后）。
- 车间温湿度稳定（18～25 ℃ / 55%～70% RH），纸张预适应。
- 不同批次/克重纸混用时重新试跑标定。

## 13. 润滑与温控系统

### 13.1 润滑

- **中央润滑系统**：每天开机看油标/油压显示确认油路畅通；油标无油或看不清 → 紧急停车检查是否漏油、油泵是否工作。中央润滑油按周期更换（常见做法一年一换，滤芯同换）。
- **手动润滑点（油嘴）**：海德堡整机油嘴按颜色区分周期——**黄色油嘴每周**打黄油，**蓝色每月**，**绿色每三个月**（以随机润滑图表为准）。
- 收纸链条、牙排周保养加油；齿轮箱油位定期检查。
- 长时间低速运转不利于滑动轴承润滑——大修或长停后，先空转让油路建立润滑再上速。

### 13.2 温控

- 墨辊温控/组合冷却机组（CombiStar 类）同时管润版液冷却与串墨辊恒温：温度失控会连锁引起乳化、糊版、网点扩大——报警时按 §9.2 的制冷诊断流程排查。
- 车间空调波动大时，早班第一批活与午后活墨色漂移属正常物理现象，靠温控机组与标准化开机流程压缩波动。

## 14. CP-tronic / CP2000 报警与错误代码

### 14.1 读懂模块化错误码（CP-tronic 时代，SM/CD 102 等）

- 错误码前缀对应**电路板模块类别与槽位**：如 **HAK** = 辅助驱动板类，"HAK 4"即该类第 4 槽位的板；**EAK**、**SEK**（安全系统相关，主面板 SEK 符号闪烁多指安全回路）等前缀同理。
- 自检结果以**十六进制**显示：每一位十六进制数代表 4 项测试，`F`（=1111）表示 4 项全部通过，`0` 表示故障或无响应；因此 `FFFF` = 16 项测试全部通过。出现非 F 位即可定位到具体测试项/板卡。
- 处置思路：记录完整错误码 → 对照该机《电气故障代码表》（随机资料或向海德堡索取）→ 优先检查对应板卡的供电、接插件、同类板换槽对比 → 再判定板卡损坏送修。

### 14.2 CP2000 / Press Center 时代

- 报警为明文信息 + 图标（如"圆圈 T" = 动态测试发现电子板故障，见 §3.2）。
- 进入**服务/诊断菜单**可查看：传感器实时状态、执行器单动测试、错误历史记录——排查间歇性故障时先导出/抄录错误历史，按时间与班次找规律。
- 典型报警处理示例：
  - "收纸处纸张未清空"而实际已清空 → 清洁/校正收纸区检测电眼。
  - "人体进入安全检测/主传动锁定" + 位置类报警 → 检查对应安全传感器与挡风管/护罩位置开关是否移位（§3.2 案例）。
  - 双张报警频发而实际无双张 → 重新按纸厚标定双张检测器。
  - Inpress/AutoRegister（联机测量）通信故障（XL 机型案例）→ 查测量系统控制盒 LED 状态、至交换机的网线/线缆、测量控制计算机是否启动。
- **凭证据换件**：CP2000 的报警多数是"检测到的现象"而非"坏件名称"，先查传感器与接线，再查执行器，最后才是板卡。

## 15. 日常保养与预防性维护计划

以下为多方资料汇总的通用基线（以本机《保养手册》/Heidelberg 保养培训为准）：

### 每班/每天

- 清洁印版滚筒、橡皮滚筒**滚枕（肩铁）**；每班清洁压印滚筒表面。
- 检查水辊靠版压力与水斗液参数（pH/导电率/温度/IPA）。
- 开机确认中央润滑油标、气压表读数正常。
- 每天至少洗车（洗橡皮布程序）一次，换活必洗。

### 每周

- 清洁飞达**分纸/送纸吸嘴**及**旋转分气阀**。
- 彻底清洁**输纸控制电眼**与递纸摆区域。
- 清洁收纸链条与牙排并加油。
- 黄色油嘴打黄油；清洗输纸线带；实测润版液 pH/导电率并洗过滤海绵。

### 每月

- 彻底清洁所有滚筒**咬牙牙垫**并逐牙检查叼力。
- 彻底疏通喷粉管路与喷嘴。
- 蓝色油嘴打黄油；清理润版液循环箱（半月一次更佳）；检查气泵滤芯/碳片。

### 每季/每年

- 绿色油嘴打黄油（每三个月）。
- 年度：更换中央润滑系统机油与滤芯、全面检测滚筒轴承游隙、齿轮侧隙、安全装置功能测试、电气柜除尘紧固。
- 高负荷机台建议购买海德堡预防性维护包/参加 PMPTC 维护培训（XL 105/106 有专门的 Level 1/2 维护课程，覆盖机械与机电系统）。

> **保养的经济性**：行业共识是海德堡机 80% 以上的突发停机可追溯到被省略的清洁与润滑项目。规范保养 = 最便宜的"维修"。
